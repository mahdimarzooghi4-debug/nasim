# نسیم

**نسیم = نظام سالمند‌یاری محله‌محور**

این مخزن مرجع رسمی مستندات، تصمیمات و توسعه محصول نسیم است.

## وضعیت فعلی

مرحله فعلی: **Business**

مبنای اولیه کسب‌وکار، طرح‌نامه «شبکه سالمندیاری شمیم» است که برای ادامه پروژه با نام «نسیم» مبنا قرار گرفته است. تغییر نام، به‌خودی‌خود مفاد کسب‌وکاری طرح اولیه را تغییر نمی‌دهد؛ هر تغییر محتوایی جدید باید به‌عنوان تصمیم مستقل ثبت شود.

## فرآیند مادر توسعه

`Business → Technical → Scrum/Product Backlog → Sprint → Code → Code Review → Stage → QA/Testing → Release Approval → Production → Monitoring → Improvement`
