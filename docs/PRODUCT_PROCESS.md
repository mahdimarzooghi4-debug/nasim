# NASIM Product Development Process

فرآیند مادر توسعه نسیم:

`Business → Technical → Scrum/Product Backlog → Sprint → Code → Code Review → Stage → QA/Testing → Release Approval → Production → Monitoring → Improvement`

## وضعیت فعلی

**Business**

در این مرحله، Concept اولیه باید به قراردادهای روشن کسب‌وکاری تبدیل شود و Open Questionها تعیین تکلیف شوند.

## قواعد

- تصمیم‌های تأییدشده در `docs/DECISIONS.md` ثبت می‌شوند.
- موضوع تعیین‌نشده نباید در Technical Design یا Code حدس زده شود.
- Technical فقط پس از تثبیت قراردادهای لازم Business آغاز می‌شود.
- Backlog باید از Business و Technical مصوب مشتق شود.
- Production فقط پس از Stage، QA/Testing و Release Approval انجام می‌شود.
- Monitoring و Improvement چرخه پس از انتشار را می‌بندند.

## خروجی مورد انتظار مرحله Business

- Problem و Scope
- Actors و مسئولیت‌ها
- Value Proposition
- Service Model و Service Catalog
- Operating Model و Referral Journey
- Economic Model
- Governance
- KPI Framework
- Pilot Contract
- Business Risks و Constraints

جزئیات Gateهای هر مرحله در ادامه پروژه تعیین و پس از تأیید ثبت خواهند شد.
